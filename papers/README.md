## Two corrections to the reading list

- The Chemprop entry links `arxiv.org/abs/2404.01926`. That identifier is an
  astrophysics preprint about pulsars; Chemprop was never posted to arXiv. Use
  the PubMed Central copy, PMC10777403.
- The Kitchen Sink post is credited to Pat Walters. The byline is Devany West
  and Jackson Burns.
